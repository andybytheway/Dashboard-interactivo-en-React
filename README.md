# Dashboard Interactivo: Huella de Carbono Global ("¿Quién contamina más?")

Este repositorio contiene el proyecto de visualización y análisis de datos centrado en el diseño y despliegue de un Dashboard Interactivo sobre las emisiones globales de dióxido de carbono (CO₂), su evolución económica y el impacto demográfico durante el periodo 1990–2025.

Nombre del Equipo: **"Alfa Buena Maravilla Onda Dinamita Escuadrón Lobo"**
- Andres Olaf Ku Torres
- Juan Pablo perez Reyes

El objetivo central del dashboard es dar respuesta analítica y visual a la pregunta: ¿Quién contamina más y cómo se relaciona esto con el crecimiento económico?

El dashboard estratégico permite desmitificar la visión sesgada que evalúa a las naciones únicamente por sus emisiones brutas totales, incorporando métricas normalizadas per cápita y coeficientes de desacoplamiento entre el Producto Interno Bruto (PIB) y la contaminación atmosférica.
